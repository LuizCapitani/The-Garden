## Sobre

Este repositório reúne o código do The Garden, um aplicativo web de produtividade gamificada que desenvolvi aplicando conceitos de design responsivo, semântica HTML, estilização com CSS e lógica em JavaScript. O objetivo é transformar o gerenciamento de tempo e tarefas em uma experiência interativa
